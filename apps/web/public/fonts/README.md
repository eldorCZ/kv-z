# Písma

Všechna písma jsou uložená u nás (žádné CDN) a mají licenci SIL Open Font License 1.1.

| Soubor | Písmo | Použití |
|---|---|---|
| `baloo2-*.woff2` | Baloo 2 (600) | nadpisy |
| `nunito-*.woff2` | Nunito (variabilní 400–800) | text, PIN a kódy (tabulkové číslice) |
| `atkinson-*-400/700.woff2` | Atkinson Hyperlegible | volba „Čitelné písmo“, načítá se jen po zapnutí |

Pokrytí češtiny ověřuje `python scripts/check-fonts.py` (fontTools), viz README, sekce Vzhled a motivy.
